# Marketing

Marketing connects a specific customer problem and credible promise to repeatable distribution. It covers positioning, messaging, launches, content, search, lifecycle communication, partnerships, community, attribution, and channel economics.

## Marketing path

1. Define the segment, painful job, trigger, alternative, and promised outcome.
2. Choose positioning and proof before producing campaigns.
3. Select one primary channel based on where the segment already discovers and evaluates solutions.
4. Connect every channel to a qualified, activated, retained, or revenue outcome.
5. Build the minimum content, landing page, lifecycle, attribution, and handoff system.
6. Run bounded experiments with explicit stop, continue, or iterate rules.
7. Scale only channels that acquire the right customers with plausible economics.
