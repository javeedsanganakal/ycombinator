## Stage contracts

| Stage | Required customer evidence | Exit criterion | Maximum idle time |
| --- | --- | --- | --- |
| Target | Observable ICP and trigger match | Named person and reason to contact |  |
| Contacted | Relevant personalized message delivered | Reply or explicit disposition |  |
| Discovery | Current workflow, impact, stakeholders, urgency explored | Problem and next step confirmed |  |
| Qualified | Pain, fit, authority, urgency, implementation, and economics fit | Evaluation plan agreed |  |
| Evaluation | Product tested against a real workflow | Success criteria met or failed |  |
| Proposal | Scope, price, stakeholders, risks, and date documented | Verbal/commercial decision |  |
| Commit | Approval, agreement, payment, and implementation path | Won or lost |  |
| Activated | Promised first value reached | Activation event recorded |  |
| Retained/expanded | Value repeated and reviewed | Renewal, expansion, referral, or churn |  |

## Weekly pipeline review

- Remove deals with no customer action or credible next step.
- Review conversion and time by stage, ICP, source, and cohort.
- Inspect loss, no-decision, activation, and churn reasons.
- Change one targeting, message, discovery, offer, or product assumption at a time.
