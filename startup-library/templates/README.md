# Startup Templates

These original templates turn the library into repeatable work. Copy the relevant file into a product repository, name an owner and review date, and replace every assumption with evidence over time.

| Template | Use it for |
| --- | --- |
| [Product and revenue brief](product-revenue-brief.md) | One source of truth for customer, value, stage, constraint, motion, monetization, metrics, and plan |
| [Customer discovery](customer-discovery.md) | Recruiting, interviewing, capturing behavior, and synthesizing evidence without pitching |
| [Positioning and messaging](positioning-and-messaging.md) | Alternatives, differentiation, value, segment, proof, and message hierarchy |
| [Founder sales pipeline](founder-sales-pipeline.md) | Account selection, discovery, qualification, evaluation, closing, activation, and learning |
| [Pricing and packaging](pricing-and-packaging.md) | Value metric, segments, plans, price hypotheses, economics, and research decisions |
| [Experiment and metrics](experiment-and-metrics.md) | Metric contracts, funnel definitions, experiment design, guardrails, and decision rules |
| [Launch readiness](launch-readiness.md) | Product, evidence, operations, trust, measurement, support, and rollback checks |
| [Weekly operating review](weekly-operating-review.md) | Compact founder cadence across customers, product, revenue, cash, risks, and decisions |

## Completion standard

- Use dates, owners, denominators, cohorts, and source links.
- Separate facts, customer reports, inferences, and hypotheses.
- Leave unknown fields marked `unknown`; do not create false precision.
- End each document with the next decision, evidence needed, owner, and deadline.
