# Startup Library

The library is the human-readable heart of this repository. It covers the startup lifecycle from finding a problem through building an organization at scale.

To apply the sales, marketing, and monetization material to a specific product, use the [`startup-revenue-strategist`](../skills/startup-revenue-strategist/) skill.

| Area | Covers |
| --- | --- |
| [Founders](founders/) | Ideas, validation, cofounders, decision-making, and founder mindset |
| [Product management](product-management/) | Discovery, strategy, prioritization, roadmaps, delivery, and metrics |
| [UX/UI](ux-ui/) | Research, flows, prototyping, usability, accessibility, and design systems |
| [Engineering](engineering/) | MVPs, architecture, quality, security, AI, and scaling |
| [Go-to-market](go-to-market/) | Positioning, pricing, launches, marketing, sales, growth, and retention |
| [Marketing](marketing/) | Positioning, messaging, content, lifecycle, channels, attribution, and growth |
| [Sales](sales/) | Founder-led sales, discovery, pipeline, closing, customer success, and revenue metrics |
| [Monetization](monetization/) | Value metrics, packaging, pricing, billing, payments, and revenue optimization |
| [Fundraising](fundraising/) | Investor research, pitch preparation, diligence, and fundraising process |
| [Finance](finance/) | Runway, budgeting, unit economics, forecasting, and reporting |
| [Legal](legal/) | Formation, equity, contracts, IP, privacy, and compliance |
| [Hiring and culture](hiring-and-culture/) | Early hires, interviews, onboarding, management, and culture |
| [Operations](operations/) | Company cadence, tooling, support, risk, and internal processes |
| [Accelerators and investors](accelerators-and-investors/) | Programs, investors, application resources, and ecosystem maps |
| [Case studies](case-studies/) | Structured analyses of startup decisions and outcomes |
| [Templates](templates/) | Reusable documents, checklists, canvases, and worksheets |
| [Tools](tools/) | Startup software and technical utilities organized by job-to-be-done |
| [Resources](resources/) | Books, courses, essays, podcasts, communities, and reference collections |
| [Knowledge base](knowledge-base/) | Curated open-source projects and public operating systems mapped to startup decisions |

## Entry format

New material should state its purpose, intended audience, startup stage, source, and last-reviewed date. Link to external material when possible; only copy it into the repository when its license permits redistribution.
