# Canonical Standards and Playbooks

This is the primary-source layer for startup decisions. Check current source text and jurisdiction before acting; use the open-source project catalog for implementation examples.

Last reviewed: 2026-09-14.

| Decision area | Start here | Use it for |
| --- | --- | --- |
| Startup execution | [Y Combinator Library](https://www.ycombinator.com/library) | Founder, product, growth, sales, fundraising, and company-building instruction |
| Early sales | [YC: How to Sell](https://www.ycombinator.com/blog/how-to-sell-by-tyler-bosmeny/) | Founder-led discovery, qualification, demos, closing, and early sales discipline |
| Search acquisition | [Google Search Essentials](https://developers.google.com/search/docs/essentials) | Eligibility, technical requirements, spam policies, and people-first discovery |

| Accessibility | [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Testable web accessibility success criteria |

## Evidence rule

Label every important statement as verified product data, direct customer behavior, customer report, authoritative external fact, comparable benchmark, inference, or hypothesis. A framework organizes evidence; it does not create it.
