# Accelerators and Investors

Accelerator directories, venture funds, angels, application guidance, selection criteria, program comparisons, geographic ecosystems, and founder communities.

## Evaluation framework

| Dimension | Questions |
| --- | --- |
| Fit | Does the program or investor match stage, sector, geography, model, round size, and company ambition? |
| Value | Which specific customers, hires, expertise, capital, infrastructure, or regulatory access can it provide? |
| Terms | What equity, fees, rights, dilution, control, exclusivity, or follow-on expectations apply? |
| Evidence | Which comparable founders completed it, what outcomes followed, and what do references say privately? |
| Opportunity cost | What work, travel, relocation, fundraising timing, or customer focus will be displaced? |
| Conflicts | Which competitors, portfolio overlaps, information rights, signaling, or future financing constraints exist? |
| Process | Who decides, on what timeline, with which documents, interviews, commitments, and expiration dates? |

Verify claims with the program or investor, speak with multiple founders including those whose companies struggled, model dilution, and review material terms with counsel. Rankings and brand recognition do not establish fit.
